# Linvell Homebrew tap

Install the signed, notarized Universal macOS app:

```sh
brew install --cask huluxiaohuowa/tap/linvell
```

Linvell requires macOS 15.6 or later and supports Apple Silicon and Intel Macs.

```sh
brew upgrade --cask --greedy huluxiaohuowa/tap/linvell
brew uninstall --cask huluxiaohuowa/tap/linvell
```

Linvell's GitHub release workflow updates `Casks/linvell.rb` after publishing a stable release and verifying the archive's SHA-256 checksum. This third-party tap is maintained by Linvell and does not imply official Homebrew inclusion or endorsement.
